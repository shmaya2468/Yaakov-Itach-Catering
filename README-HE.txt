מעדני יעקב — גרסה V4 | אתר תדמית רספונסיבי

פתיחה במחשב:
1. חלצו את כל תוכן קובץ ה-ZIP לתיקייה אחת.
2. פתחו את index.html, או פתחו את התיקייה ב-VS Code באמצעות Live Server.

העלאה ל-Netlify:
גררו את התיקייה כולה אל Netlify Drop (או העלו את ה-ZIP). index.html נמצא בשורש התיקייה.

קבצים עיקריים:
index.html — מבנה האתר בעברית
styles.css — עיצוב, אנימציות והתאמה למובייל
app.js — תפריט נייד, גלריה, הגדלה, נצנצים, טופס ו-WhatsApp
assets/images — תמונת ראשית למחשב ולנייד, הלוגו, התפריט, 15 תמונות גלריה ועוד
assets/video — שלושה סרטוני וידאו מותאמים לשימוש באתר
